# ![](https://wsrv.nl?url=raw.githubusercontent.com/icarusloader/.github/416d97ada95d88f771b4542b41769d8241d99bad/media/icarus.svg&height=32) icarusloader basic mod API

A mod that uses the basic module can be really simple. One just organizes ones files like this:

```
example
 └ basic
    └ content
       └ textures
          └ MouseLockedCursor.png
    └ ExtraContent
       └ ...
```
